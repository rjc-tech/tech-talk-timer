# 雑談Webアプリケーション要件定義（Phase1）

## 1. プロジェクト概要

**アプリ名**: Tech Talk Timer

**目的**: 帰社活動時における「技術的な」雑談を円滑に進めるためのファシリテーション支援ツール

**対象ユーザー**: チームでの雑談・アイスブレイクを行う人々

**開発期間**: 3回の帰社日

## 2. 機能要件

### 2.1 主要機能
| 機能ID | 機能名 | 説明 | 優先度 |
|--------|--------|------|--------|
| F01 | 参加者登録 | 複数の参加者名を入力・管理 | 高 |
| F02 | ファシリテーター選出 | 登録された参加者からランダムに1名選出 | 高 |
| F03 | トークテーマ表示 | 事前登録されたテーマ候補をランダム表示 | 高 |
| F04 | 時間設定 | トーク時間を選択（1分/3分/5分など） | 高 |
| F05 | タイマー機能 | カウントダウンタイマーの開始/停止 | 高 |

### 2.2 画面遷移
```
[TOP画面] → [参加者入力画面] → [セッション画面（メイン）]
                                    ├─ ファシリテーター表示
                                    ├─ トークテーマ表示
                                    └─ タイマー表示
```

## 3. 技術仕様

**フロントエンド**: React

**バックエンド**: Go

**データベース**: なし

**通信方式**: REST API (JSON)

## 4. データ構造

### 4.1 参加者（participants）
```
- id: 整数（自動採番）
- name: 文字列（50文字以内）
- created_at: タイムスタンプ
```

### 4.2 トークテーマ（talk_themes）
```
- id: 整数（自動採番）
- theme: 文字列（200文字以内）
- category: 文字列（任意）
- created_at: タイムスタンプ
```

## 5. API設計

| エンドポイント | メソッド | 説明 |
|---------------|----------|------|
| /api/themes/random | GET | ランダムテーマ取得 |

## 6. 画面構成

### 6.1 TOP画面
- アプリケーションタイトル、説明、使い方を表示する
- 開始ボタン

### 6.2 参加者入力画面
- 参加者名入力フォーム（複数入力可）
- 追加/削除ボタン
- 次へボタン

### 6.3 セッション画面
* ファシリテーター表示エリア（大きく表示）
* トークテーマ表示エリア
  * 候補は3つ
  * 選択したテーマが分かるようにする
* 時間選択ドロップダウン
* タイマー表示（大きく見やすく）
* 開始/停止ボタン
* 新しいセッションボタン

## 7. 制約事項・前提条件
- ユーザー認証機能は実装しない
- レスポンシブデザイン対応（PC優先）
- ブラウザ: Chrome最新版対応
