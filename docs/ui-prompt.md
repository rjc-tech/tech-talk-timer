以下のWebアプリケーションのモックアップを作成してください。

ソースコードは HTML + TailwindCSS(CDN) + JavaScriptでお願いします。

## アプリケーションの概要

* 複数人で雑談するときに使用するアプリケーション

## ターゲットユーザー

* ITエンジニア向け
* ブラウザでの使用を想定

## ユーザーがやりたいこと

* 参加者を入力する
* ファシリテーターをランダムで一人選出する
* トークテーマの候補が3つ表示される
* トークテーマを1つ選択する
* トーク時間を選択する
* トーク開始（タイマー起動）
* トーク終了（タイマーストップ）

## 画面構成

```
[TOP画面] → [参加者入力画面] → [セッション画面（メイン）]
                                   ├─ ファシリテーター表示
                                   ├─ トークテーマ表示
                                   └─ タイマー表示
```

### TOP画面

* アプリケーションタイトル、説明、使い方を表示する
* 開始ボタン

### 参加者入力画面

* 参加者名入力フォーム（複数入力可）
* 追加/削除ボタン
* 次へボタン

### セッション画面

* ファシリテーター表示エリア（大きく表示）
* トークテーマ表示エリア
  * 候補は3つ
  * 選択したテーマが分かるようにする
* 時間選択ドロップダウン
* タイマー表示（大きく見やすく）
* 開始/停止ボタン
* 新しいセッションボタン

## UI/UXの要件

* 2025年のトレンドを取り入れつつシンプルなデザインにすること
  * 将来的にReactへ移行するため、スムーズに移行できるようにしてほしい
* 可能な限りレスポンシブ対応をすること
